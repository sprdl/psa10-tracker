# Step 1c: find missing PSA pop pages

Part of the full price check (`pricecheck/FULL-CHECK.md`, which holds the shared rules: credentials, publishing, the chat message). Read this file when `plan.py` printed a `PSAPOP MISSING` line, or an evaluation needs a new card's PSA pop page.

**1c. Find missing PSA pop pages** (every full check). If `plan.py` printed a `PSAPOP MISSING` line, those cards have regular PSA10 sales (a PSA10 ask and a verdict other than Defer) but no PSA pop page on file, so they have no population or gem rate (no DIY tab, no gem rate for evaluations). On Mondays the list also includes Defer cards that already have a PSA10 ask, to catch the week PSA starts listing them; if PSA has no row for one yet, leave it and say so once. For up to 3 per run: in the browser (signed in to psacard.com), open `https://www.psacard.com/pop/tcg-cards/156940`, pick the set's release year, set the year page's "Show" menu to 250 and page through it to find the set ("Pokemon Japanese <code>-<English set name>", e.g. "Pokemon Japanese Sv8a-Terastal Fest EX"; older sets read "Pokemon Japanese Sword & Shield <name>"; English promos "Pokemon Svp EN-SV Black Star Promo"). Open the set page, find the card's row (card number as PSA writes it, e.g. "090"; the English name), then save it with `python3 scripts/card_requests.py set <snkrdunk_id> psa_pop_url=/pop/tcg-cards/<year>/<slug>/<id> psa_pop_no=<number> psa_pop_name="<English name fragment>"` and run `python3 pricecheck/plan.py` and `python3 pricecheck/jsrun.py run psa_pop` again so today's `PSAPOP` (and the psa_pop RUN call) include it. Also say "PSA pop page added: <name>" in the chat message.
